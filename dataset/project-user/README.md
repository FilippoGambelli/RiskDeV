This folder contains two Python scripts to generate **fake Python projects and users** and then **analyze their packages for risk scores and vulnerabilities**.

---

### Scripts Overview

### 1. `generate_projects_and_users.py`

**Purpose:**
Generates fake Python projects and users. Each project has a set of installed Python packages, a description, last update date, and linked users (admin and collaborators).

**What it does:**

* Generates `PROJECT_COUNT` projects with unique names.
* Generates `USER_COUNT` users with unique usernames.
* Assigns each project an admin and 0–3 collaborators.
* Creates realistic package metadata using temporary virtual environments (`pip list` output). Packages installed in temporary virtual environments are used to simulate real project dependencies.

**Output:**

* `projects.json` — list of projects with metadata and linked users.
* `users.json` — list of users with roles, email, and linked projects.



### 2. `score_project_packages.py`

**Purpose:**
Adds **risk scores** and **vulnerability counts** to the packages of the generated projects using a scored package database.

**What it does:**

* Reads the projects from `projects.json`.
* Reads a scored package database (e.g., `../pkg-cve/package.json`) containing:

  * `package_name`
  * `version`
  * `risk_score`
  * `vulnerabilities` (list)
* Maps each package version to its risk score and number of vulnerabilities.
* Updates each project’s packages with:

  * `risk_score`
  * `vulnerabilities_count`

**Input:**

* `projects.json` — generated by the first script.
* `../pkg-cve/package.json` — your scored package database.

**Output:**

* Updated `projects.json` with risk scores and vulnerabilities count for each package.

---

### Workflow

1. **Generate projects and users first**

   ```bash
   python generate_projects_and_users.py
   ```

   This will create `projects.json` and `users.json`.

2. **Score the project packages**

   ```bash
   python score_project_packages.py
   ```

   This will read `projects.json` and update each package with `risk_score` and `vulnerabilities_count`.
